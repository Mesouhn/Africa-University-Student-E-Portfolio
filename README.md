\# Africa University Student E-Portfolio Management System



\## Project Overview



The Africa University Student E-Portfolio Management System is a web-based platform that enables students to manage their academic and extracurricular achievements in one centralized location.



Students can submit achievements for verification, maintain their portfolios and track submission statuses. Authorized staff members review submissions, while the Portal Administrator manages staff accounts and oversees achievement records.



\## Main Features



\- \*\*Student Registration and Login:\*\* Secure account access.

\- \*\*Student Dashboard:\*\* Centralized view of student portfolio information.

\- \*\*Achievement Submission:\*\* Students submit achievements for verification.

\- \*\*Achievement Tracking:\*\* Students monitor Pending, Verified and Rejected submissions.

\- \*\*Staff Review:\*\* Authorized staff approve or reject achievements with reasons.

\- \*\*Administrator Oversight:\*\* The administrator manages staff accounts and oversees achievement records.

\- \*\*Role-Based Access:\*\* Users access functions according to their assigned roles.



\## Technologies Used



\- HTML

\- CSS

\- JavaScript

\- Firebase Authentication

\- Cloud Firestore

\- Firebase Admin SDK

\- Netlify Functions

\- Git and GitHub



\## Security



The system uses Firebase Authentication, backend token verification, role-based permissions and Firestore security rules to protect user accounts and information. Sensitive credentials are kept outside the public source repository.
